## ✨ Key Features

- **🌐 Live Production Deployment** — Accessible worldwide at `taskflix.rkdapp.site`
- **📁 Project-Centric Management** — Organize tasks into dedicated projects with progress bars
- **📊 6-Column Trello Kanban** — Backlog, To Do, In Progress, Done, On Hold, Canceled
- **🖐️ Drag-and-Drop Workflow** — Native HTML5 drag-and-drop card status updates via AJAX
- **🎨 Glassmorphism & Obsidian Aesthetic** — Sleek dark theme with blur backdrop effects
- **✨ Animated Vanta.js Blue Dots** — Interactive particle dot wave background
- **⚡ Real-time AJAX Operations** — Complete or reassign tasks without page reloads
- **🔍 Task Filtering & Sorting** — Filter by project, priority, and completion status
- **🔓 Open Source & Modular** — Fully customizable Django architecture

## 🚀 Quick Open-Source Installation Guide

Anyone can clone, modify, and run TaskFlix locally or deploy it to their own cloud server:

```bash
# 1. Clone repository
git clone https://github.com/logicbyroshan/smart-tasks-manager.git
cd smart-tasks-manager

# 2. Create and activate virtual environment
python -m venv venv
venv\Scripts\activate      # On Windows
# source venv/bin/activate  # On macOS/Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run database migrations
python manage.py migrate

# 5. Launch local server
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser to view TaskFlix!

## 📖 Project Structure & Navigation

- **Dashboard**: High-level overview of task statuses and recent project assignments.
- **Manage Tasks**: Search, sort, and manage all task items.
- **Manage Projects**: Project dashboard with progress bars and direct links to dedicated Kanban boards.
- **Manage Kanban**: Trello-style 6-column board with drag-and-drop card movement and project selector dropdown.
- **Settings**: User profile and account preferences.
