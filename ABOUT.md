# ℹ️ About TaskFlixx

**TaskFlixx** is an open-source task orchestration and project management platform built to solve common pain points in task productivity tools: sluggish performance, bloated layouts, and distracting UI clutter.

---

## 🎯 The Vision

1. **Pure Speed & Zero Clutter**: No heavy client frameworks or bloated JavaScript bundles. Built on native web standards (HTML5 Canvas, Vanilla CSS, ES6+ JS) and lightweight Django backend.
2. **OLED Visual Excellence**: Deep pitch-black theme engineered for modern OLED displays, enhancing contrast and minimizing eye strain during long working sessions.
3. **Ambient Interactivity**: Dynamic background canvas bringing subtle living energy to your workspace.
4. **Fluid Workflow Execution**: 6-state Kanban boards, multi-dimensional task filters, instant search, and integrated AI assistant for fast task breakdown.
